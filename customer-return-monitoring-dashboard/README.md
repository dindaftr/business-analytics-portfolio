# Customer Return Monitoring Dashboard

## Overview

This project demonstrates an operational dashboard designed to monitor customer return transactions in a financial technology company.

The dashboard aims to improve operational efficiency by replacing manual spreadsheet reporting with a centralized monitoring dashboard.

---

## Business Background

Customer return transactions were previously monitored manually using spreadsheets.

This process created several challenges:

- Manual tracking
- Slow reporting
- Difficult monitoring
- Higher operational risk

---

## Objectives

- Monitor customer return transactions
- Improve operational visibility
- Reduce manual reporting
- Support faster decision making

---

## Dashboard Features

- KPI Cards
- Monthly Trends
- Return Status
- Operational Summary

---

## Technologies

- Power BI
- SQL
- Microsoft Excel
